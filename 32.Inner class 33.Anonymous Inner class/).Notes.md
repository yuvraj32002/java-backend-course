JAVA — INNER CLASS
═════════════════════════════════════════════════════
1. What is an Inner Class?

An inner class is a class declared inside another class.

class Outer {
    class Inner {
        // Inner class members
    }
}

# Key Point: The inner class can access all members of the outer class, including private members.

# An outer class can access inner-class members only through an object of the inner class.
════════════════════════════════════════════════════════════
2. Why Use Inner Classes?

1. Encapsulation: Can access private members of the outer class.

2. Code Organization: Groups closely related classes together.

3. Outer Class Access: A non-static inner class maintains a connection with its outer-class object.

4. Namespace Management: Nesting helps avoid naming conflicts.

4. Member Inner Class: 

# A member inner class is a non-static class declared directly inside another class.

class Outer {
    private int x = 100;
    class Inner {
        void display() {
            System.out.println(x);
        }
    }
}
# Creating its Object: A member inner class requires an outer-class object.

Outer outer = new Outer();
Outer.Inner inner = outer.new Inner();
inner.display();

Important

Outer object
     ↓
Inner object

# The inner object is associated with a specific outer object.

Static Members:

# * Before Java 16, member inner classes could not have static members except static final constants.
# * From Java 16, they can have static members, subject to Java’s restrictions for inner classes.
════════════════════════════════════════════════════════════
5. Method-Local Inner Class:

# A method-local inner class is declared inside a method.

class Outer {
    void outerMethod() {
        class Inner {
            void innerMethod() {
                System.out.println("Hello");
            }
        }
        Inner obj = new Inner();
        obj.innerMethod();
    }
}
# Important: The class is available only within the scope where it is declared, so its object is normally created inside that method.

outerMethod()
     │
     └── Inner class
            │
            └── object

# Accessing Local Variables: From Java 8, a method-local inner class can access local variables that are final or effectively final.

void method() {
    int x = 98;       // effectively final
    class Inner {
        void show() {
            System.out.println(x);
        }
    }
}
# x must not be reassigned after initialization.

# Restrictions: A method-local inner class:

# * Cannot be declared private, protected, static, or transient.
# * Can be abstract or final, but not both.
════════════════════════════════════════════════════════════
6. Static Nested Class:

# A static nested class is declared using static inside another class.

class Outer {
    static int x = 50;
    static class Inner {
        void display() {
            System.out.println(x);
        }
    }
}

# Creating Object: Unlike a member inner class, it does not require an outer-class object.

Outer.Inner obj = new Outer.Inner();
obj.display();

# Access: A static nested class can directly access:
Outer class
     │
     ├── static members ✓
     │
     └── instance members ✗

To access an outer instance member, an appropriate outer-class object/reference is needed.

7. Anonymous Inner Class:

# An anonymous inner class is a class without a name. It is declared and instantiated at the same time.

# It is mainly used when an implementation is required only once.
EXAMPLE:

Parent obj = new Parent() {
    // implementation
};

# There are two common uses:-

# A. Anonymous Class as a Subclass

class Demo {
    void show() {
        System.out.println("Demo");
    }
}
class Main {
    public static void main(String[] args) {
        Demo obj = new Demo() {
            @Override
            void show() {
                System.out.println("Anonymous class");
            }
        };
        obj.show();
    }
}
Here, an unnamed class extends Demo and overrides show().

# B. Anonymous Class as Interface Implementation

interface Hello {
    void greet();
}
class Main {
    public static void main(String[] args) {
        Hello obj = new Hello() {
            public void greet() {
                System.out.println("Hello");
            }
        };
        obj.greet();
    }
}

Here, the anonymous class implements Hello.

Important Properties

* Has no class name.
* Declared and instantiated together.
* Suitable for one-time implementations.
# * Cannot have a constructor because it has no name.
* Commonly used in event handling and callback-style code.

9. All Four Types — Quick Comparison

Type                    | Declared Where?                    | Outer Object Needed?
------------------------|------------------------------------|----------------------
Member Inner Class      | Directly inside another class      | Yes
Method-Local Inner Class| Inside a method                    | Yes (non-static)
Static Nested Class     | Inside another class using static  | No
Anonymous Inner Class   | Inside an expression/statement     | Depends on context

# 10. Most Important Object-Creation Syntax

# Member Inner Class:

Outer outer = new Outer();
Outer.Inner inner = outer.new Inner();

# Static Nested Class:  Outer.Inner inner = new Outer.Inner();

# Method-Local Class

void method() {
    class Inner { }
    Inner obj = new Inner();
}

# Anonymous Class

Interface obj = new Interface() {
    // implementation
};

11. Quick Revision

INNER CLASS
│
├── Member Inner
│     └── Non-static → needs outer object

├── Method-Local

│

      └── No name + one-time implementation

Must Remember

1. Inner class = class inside another class.
2. Non-static inner class can access outer
   class members, including private members.
3. Member inner class needs an outer object.
4. Method-local inner class is declared inside
   a method.
5. From Java 8, local inner classes can access
   final/effectively-final local variables.
6. Static nested class does not require an
   outer-class object.
7. Anonymous class has no name and is created
   and implemented in one expression.
8. Anonymous classes are useful for one-time
   implementations.
9. Anonymous classes cannot have constructors.
10. Java provides four main types:
    Member, Method-Local, Static Nested,
    and Anonymous.

ONE-LINE DEFINITION

An inner class is a class declared inside another class, mainly used for better encapsulation, organization, and representing closely related functionality.
