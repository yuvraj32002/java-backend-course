------------------------------------------------
Encapsulation in Java
------------------------------------------------
1. What is Encapsulation?
Encapsulation is an OOP concept in which:

# Data (variables) + Methods that operate on that data → are bundled together inside a class.

# It also restricts direct access to the internal data and provides controlled access through methods.

Example

class Student {
    private int age;
    public void setAge(int age) {
        this.age = age;
    }
    public int getAge() {
        return age;
    }
}

Here:

* age → data
* setAge() → modifies data
* getAge() → accesses data
* All are combined inside the Student class.
------------------------------------------------
2. How is Encapsulation Achieved?
------------------------------------------------
Encapsulation is mainly achieved by:
① Declare data as private: This prevents direct access from outside the class.

② Provide Getter and Setter Methods: Getter → reads data, Setter → modifies data

③ Add Validation: A setter can control what values are allowed.

public void setAge(int age) {
    if(age >= 0) {
        this.age = age;
    }
}
Now invalid values can be prevented.
------------------------------------------------
4. Getter vs Setter
------------------------------------------------
Method	|Purpose	        |Example
------------------------------------------------
Getter	|Reads/returns data	|getAge()
Setter	|Modifies/sets data	|setAge()

------------------------------------------------
6. Advantages of Encapsulation
------------------------------------------------
* Data Protection → prevents direct access to internal data.
* Controlled Access → decides how data can be read or modified.
* Validation → invalid values can be rejected.
* Maintainability → internal implementation can be changed without  
  affecting outside code.
* Reduced Dependency → outside code depends less on internal   
  implementation.
* Data + Methods Together → related data and behavior remain inside 
  one class.
------------------------------------------------
7. Data Hiding vs Encapsulation
------------------------------------------------
Data Hiding vs Encapsulation

Feature             Data Hiding                         Encapsulation
--------------------------------------------------------------------------------
Meaning             Restricts direct access            Bundles data and methods
                    to data.                            together in a class.

Main Focus          Protecting data from                Combining data and
                    unauthorized access.                related methods.

Achieved By         Mainly using access                 Using classes, access
                    modifiers like private.             modifiers, getters,
                                                        setters, etc.

Scope               Narrow concept.                     Broader OOP concept.

Example             private int age;                    class Student {
                                                            private int age;
                                                            getAge();
                                                            setAge();
                                                        }

Purpose             Prevent direct access              Provide controlled
                    to internal data.                   access to data.
--------------------------------------------------------------------------------
Data Hiding
     ↓
"Who can access the data?"
-----------------------------------
Encapsulation
     ↓
"How are data + behavior organized
and accessed together?"
