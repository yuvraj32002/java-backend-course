Private Constructor — Main Points
-------------------------------------------
1. Private Constructor

* A constructor declared using the private access modifier is called a private constructor.
* It cannot be accessed directly from outside the class.

class Demo {
    private Demo() {
    }
}

⸻

2. Direct Object Creation from Outside

Demo obj = new Demo();   // ❌ Error

* This is not allowed because the constructor is private.

⸻

# 3. Object Creation from Inside the Class

class Demo {
    private Demo() {
    }
    static void create() {
        Demo obj = new Demo();   // ✅ Allowed
    }
}

* A private constructor can be accessed from within the same class.
* Therefore, an object can be created inside the class.

⸻

4. What Can We Do with That Object?

An object created inside the class can be used normally:

* Call instance methods
* Access accessible instance variables
* Pass the object to another method
* Store the object in a variable
* Return the object from a method

Example:

static void create() {
    Demo obj = new Demo();
    obj.show();   // ✅
}

⸻

# 5. Can We Use the Object Outside the Class?
# Yes...The object can be made available outside the class by returning it from a method.

class Demo {
    private Demo() {
    }
    void show() {
        System.out.println("Hello");
    }
    static Demo createObject() {
        Demo obj = new Demo();
        return obj;
    }
}

Then:

class Main {
    public static void main(String[] args) {
        Demo obj = Demo.createObject();
        obj.show();   // ✅
    }
}

⸻

6. Important Difference

Demo obj = new Demo();

❌ Not allowed outside the class

because the constructor is private.

Demo obj = Demo.createObject();

✅ Allowed

because the object is created inside the class, and the reference is returned to the caller.

⸻

7. Main Purpose of a Private Constructor

A private constructor is mainly used when we want to control object creation.

Common uses:

* Singleton Design Pattern
* Factory Pattern
* Utility classes
* Preventing unnecessary object creation

⸻

⭐ Remember
Private constructor does NOT mean objects can never be created.
It means:
Objects cannot be created directly from outside the class using new.
The class itself can create the object and can return/provide that object to outside code.
