WRAPPER CLASSES IN JAVA

────────────────────────────────────────────────────────────

1. What are Wrapper Classes?

Java has 8 primitive data types:

byte, short, int, long, float, double, char, boolean

Wrapper classes convert these primitive values into objects.

Primitive Type  →  Wrapper Class
byte            →  Byte
short           →  Short
int             →  Integer
long            →  Long
float           →  Float
double          →  Double
char            →  Character
boolean         →  Boolean

Example

int x = 10;
Integer obj = 10;

Here:

int     → primitive
Integer → wrapper object

────────────────────────────────────────────────────────────

2. Why Do We Need Wrapper Classes?

Wrapper classes are mainly required when a primitive value needs to be treated as an object.

Important use: Collections

Java Collections work with objects, not primitive types.

ArrayList<Integer> numbers = new ArrayList<>();
numbers.add(10);
numbers.add(20);

Here int values are automatically converted into Integer objects.

────────────────────────────────────────────────────────────

3. Autoboxing

Autoboxing is the automatic conversion of a primitive into its corresponding wrapper object.

int x = 10;
Integer obj = x;
int
 ↓
Autoboxing
 ↓
Integer

Java internally performs the required conversion.

────────────────────────────────────────────────────────────

4. Unboxing

Unboxing is the automatic conversion of a wrapper object into its corresponding primitive.

Integer obj = 10;
int x = obj;
Integer
   ↓
Unboxing
   ↓
int

────────────────────────────────────────────────────────────

5. String to Primitive

Wrapper classes provide parseXXX() methods for converting strings into primitive values.

Example

int x = Integer.parseInt("100");
double d = Double.parseDouble("25.5");
"100"
  ↓
Integer.parseInt()
  ↓
100 (int)

Common Methods

Integer.parseInt()
Double.parseDouble()
Long.parseLong()
Float.parseFloat()

────────────────────────────────────────────────────────────

6. parseXXX() vs valueOf()

This is an important distinction.

parseInt()

Returns a primitive int.

int x = Integer.parseInt("100");

valueOf()

Returns an Integer object.

Integer x = Integer.valueOf("100");
"100"
 │
 ├── parseInt() → int
 │
 └── valueOf()  → Integer

────────────────────────────────────────────────────────────

7. Important Character Methods

The Character class provides useful methods for working with characters.

Character.isDigit('5');       // true
Character.isLetter('A');     // true
Character.isUpperCase('A');  // true
Character.isLowerCase('a');  // true

It also provides case conversion:

Character.toUpperCase('a');
Character.toLowerCase('A');

────────────────────────────────────────────────────────────

8. Wrapper Classes and null

Wrapper classes are objects, so they can store null.

Integer x = null;

Primitive types cannot:

int x = null;    // Error

Important

If a null wrapper is automatically unboxed:

Integer x = null;
int y = x;

it causes:

NullPointerException

────────────────────────────────────────────────────────────

9. Wrapper Classes are Immutable

Wrapper objects cannot have their value changed after creation.

Integer x = 10;
x = 20;

The original Integer value is not modified; x is simply assigned another value.

────────────────────────────────────────────────────────────

10. Wrapper Classes and ==

Wrapper objects should generally be compared using equals() when checking their values.

Integer a = 100;
Integer b = 100;
System.out.println(a.equals(b));

Output:

true

Avoid using == as the general method for comparing wrapper values because == compares object references.

==        → reference comparison
equals()  → value/equality comparison

────────────────────────────────────────────────────────────
