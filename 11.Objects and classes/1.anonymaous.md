              ANONYMOUS OBJECT — JAVA
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. DEFINITION

# • An anonymous object is an object that is created without storing its reference in a reference variable.

• It is generally used when an object is needed only once.

Example:

new Dog("Tuffy", "Papillon", 5, "White");

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
2. NORMAL OBJECT vs ANONYMOUS OBJECT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

NORMAL OBJECT:

Dog tuffy = new Dog("Tuffy", "Papillon", 5, "White");

Here:

new Dog(...)
     ↓
Object created
     ↓
Reference stored in
     ↓
tuffy

We can use the object multiple times:

System.out.println(tuffy.getName());
System.out.println(tuffy.getAge());


ANONYMOUS OBJECT:

new Dog("Tuffy", "Papillon", 5, "White");

Here:

new Dog(...)
     ↓
Object created
     ↓
Reference NOT stored in a variable

Therefore, it is called an anonymous object.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
5. ANONYMOUS OBJECT WITH println()
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Example:

System.out.println(
      new Dog("Tuffy", "Papillon", 5, "White")
);

Flow:

new Dog(...)
      ↓
Dog object created
      ↓
Passed directly to println()
      ↓
toString() used for object representation
      ↓
String returned
      ↓
Printed


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
6. ANONYMOUS OBJECT WITH METHOD CALL
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Example:

new Dog("Tuffy").bark();

The object is:

new Dog("Tuffy")

The method is called immediately: .bark()

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
7. MAIN CHARACTERISTIC
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Anonymous object:

• Has an object in memory.
• Does NOT have a reference stored in a variable.
• Usually used immediately.
• Usually useful when the object is required only once.
• Cannot conveniently be reused through a reference variable.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
9. ANONYMOUS OBJECT IN METHOD ARGUMENT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

An anonymous object can be passed directly as an argument.

Example:

printDog(new Dog("Tuffy"));

Instead of:

Dog d = new Dog("Tuffy");
printDog(d);

Both can pass a Dog object to printDog(), but the first one uses an anonymous object.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
10. ADVANTAGE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

• Useful when an object is required only once.
• Reduces unnecessary reference variables.
• Can make short/simple code more concise.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
11. DISADVANTAGE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

• The object cannot be easily reused through a reference variable.
• If the same object is needed multiple times, a reference variable should normally be created.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
# 12. IMPORTANT: ANONYMOUS OBJECT ≠ ANONYMOUS CLASS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
ANONYMOUS OBJECT:
Object created without storing its reference in a variable.

Example: new Dog("Tuffy");

# ANONYMOUS CLASS:
# A class created without giving the class a name.

# Example: Animal a = new Animal() {

#    @Override
#    void sound() {
#        System.out.println("Animal sound");
#    }
# };

Anonymous Object
→ No reference variable for the object

Anonymous Class
→ No explicit class name

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
16. MOST IMPORTANT POINT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Anonymous does NOT mean the object does not exist.

The object is still created in memory.

"Anonymous" only means that its reference is not stored in a named reference variable.


FINAL FLOW:

new Dog(...)
     ↓
Object created
     ↓
Reference NOT stored in a variable
     ↓
Anonymous Object
     ↓
Used immediately
     ↓
Object becomes eligible for garbage collection when
there are no references to it.
