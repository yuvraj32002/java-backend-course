UPCASTING AND DOWNCASTING IN JAVA — CLASS NOTES
────────────────────────────────────────────────────────────
1. Introduction: Casting means converting a reference of one type into a reference of another compatible type. In Java, when inheritance is involved, object reference casting is mainly of two types:

                 Type Casting
                      │
             ┌────────┴────────┐
             ↓                 ↓
         Upcasting         Downcasting
             │                 │
      Child → Parent      Parent → Child

Both are related to inheritance and polymorphism.
────────────────────────────────────────────────────────────
2. Basic Inheritance Structure
────────────────────────────────────────────────────────────
Consider:

class Animal {
    void eat() {
        System.out.println("Animal eats");
    }
}
class Dog extends Animal {
    void bark() {
        System.out.println("Dog barks");
    }
}

The relationship is:

        Animal
           ↑
           |
          Dog
Dog is a animal.
Here:
* Animal → Parent / Superclass
* Dog → Child / Subclass
────────────────────────────────────────────────────────────
3. Upcasting
────────────────────────────────────────────────────────────
Definition: Upcasting means converting a reference of a child class into a reference of its parent class.

Child → Parent

Dog d = new Dog();
Animal a = d;

Here:   Dog object
            │
            ↓
      Animal reference

The object is still a Dog object, but it is being referenced through an Animal reference.

# Explicit Casting: Upcasting can also be written as:

Animal a = (Animal) d;

# However, the explicit cast is normally unnecessary because Java performs the conversion automatically.
────────────────────────────────────────────────────────────
4. Why is Upcasting Safe?
────────────────────────────────────────────────────────────
# A child object is also an instance of its parent type.

For example: Dog IS-A Animal

Therefore:

Dog d = new Dog();
Animal a = d;

is valid.

Java automatically performs this conversion.

Dog
 │
 │ Upcasting
 ↓
Animal
# Key Point: Upcasting is generally safe and does not require an explicit cast.
────────────────────────────────────────────────────────────
5. What Can Be Accessed After Upcasting?
────────────────────────────────────────────────────────────
Suppose:

class Animal {
    void eat() {
        System.out.println("Eating");
    }
}
class Dog extends Animal {
    void bark() {
        System.out.println("Barking");
    }
}

Now:

Dog d = new Dog();
Animal a = d;

Through a, you can access members available through the Animal reference:

a.eat();

But:

a.bark();

will not compile because bark() is not declared in Animal.

# Important Concept: 

# Reference Type
      ↓
Determines what members can be accessed
Actual Object
      ↓
Determines which overridden method executes

This distinction is extremely important in Java polymorphism.
────────────────────────────────────────────────────────────
6. Method Overriding and Upcasting
────────────────────────────────────────────────────────────
Upcasting is commonly used with runtime polymorphism.

Example:

class Animal {
    void sound() {
        System.out.println("Animal sound");
    }
}
class Dog extends Animal {
    @Override
    void sound() {
        System.out.println("Dog barks");
    }
}

Now:

Animal a = new Dog();
a.sound();

Output

Dog barks

Although the reference type is Animal, the actual object is Dog.

Animal reference
       │
       ↓
   Dog object
       │
       ↓
Overridden Dog.sound()

This is runtime method dispatch.
────────────────────────────────────────────────────────────
7. Downcasting
────────────────────────────────────────────────────────────
# Definition: Downcasting means converting a reference of a parent class into a reference of a child class.
# Parent → Child

Example:
Animal a = new Dog();
Dog d = (Dog) a;

Here:

Animal reference
       │
       │ Downcasting
       ↓
Dog reference

# Unlike upcasting, downcasting generally requires an explicit cast.
────────────────────────────────────────────────────────────
8. Why is Downcasting Explicit?
────────────────────────────────────────────────────────────
# A parent reference can refer to objects of different child classes.

For example:

Animal a = new Dog();

or:

Animal a = new Cat();

# If Java automatically converted every Animal reference to Dog, it could be incorrect. Therefore, Java requires the programmer to explicitly specify the intended child type.

Dog d = (Dog) a;
────────────────────────────────────────────────────────────
9. Safe Downcasting
────────────────────────────────────────────────────────────
# Downcasting is safe when the actual object is really an instance of the target child class.
Example:

Animal a = new Dog();
Dog d = (Dog) a;
d.bark();

This is valid because:

Actual object = Dog
Target type   = Dog

Therefore, the cast succeeds.
────────────────────────────────────────────────────────────
10. Unsafe Downcasting
────────────────────────────────────────────────────────────
Consider:

Animal a = new Animal();
Dog d = (Dog) a;

# This compiles, but at runtime it results in: ClassCastException, because the actual object is an Animal, not a Dog.

Animal reference
       │
       ↓
Animal object
       │
       X
       ↓
     Dog

# Important Rule: The actual object must be compatible with the type to which you are downcasting.
────────────────────────────────────────────────────────────
11. instanceof with Downcasting
────────────────────────────────────────────────────────────
# To avoid an invalid downcast, Java provides the instanceof operator.

Example

Animal a = new Dog();
if (a instanceof Dog) {
    Dog d = (Dog) a;
    d.bark();
}

Here:

             Animal a
                 │
                 ↓
          Is it a Dog?
                 │
             instanceof
                 │
          ┌──────┴──────┐
         Yes            No
          │              │
          ↓              ↓
       Downcast        Don't cast

# This helps prevent ClassCastException.
────────────────────────────────────────────────────────────
12. Upcasting vs Downcasting
────────────────────────────────────────────────────────────
Feature	           Upcasting	           Downcasting
Direction	       Child → Parent	       Parent → Child
Explicit cast	   Usually not required	   Required
Automatic	       Yes	                   No
Safety	           Generally safe	       Can be unsafe
Main use	       Polymorphism	           Access child-specific members
Runtime exception  Normally not an issue   Can cause ClassCastException
────────────────────────────────────────────────────────────
13. Complete Example
────────────────────────────────────────────────────────────
class Animal {
    void eat() {
        System.out.println("Animal eats");
    }
}
class Dog extends Animal {
    void bark() {
        System.out.println("Dog barks");
    }
}
public class Main {
    public static void main(String[] args) {
        // Upcasting
        Animal a = new Dog();
        a.eat();
        // Downcasting
        Dog d = (Dog) a;
        d.bark();
    }
}

Flow

                new Dog()
                   │
                   ↓
            Dog reference
                   │
                Upcasting
                   ↓
           Animal reference
                   │
              Downcasting
                   ↓
              Dog reference

14. Upcasting with Multiple Child Classes
────────────────────────────────────────────────────────────
Suppose:

class Animal {
    void eat() {
        System.out.println("Eating");
    }
}
class Dog extends Animal {
    void bark() {
        System.out.println("Barking");
    }
}
class Cat extends Animal {
    void meow() {
        System.out.println("Meowing");
    }
}

We can write:

Animal a1 = new Dog();
Animal a2 = new Cat();

This is one of the major benefits of upcasting.

                 Animal
                /      \
               /        \
             Dog        Cat
              ↑          ↑
              │          │
         Animal ref   Animal ref

The parent reference can refer to objects of different subclasses.
────────────────────────────────────────────────────────────
16. Important Concept: Reference Type vs Object Type
────────────────────────────────────────────────────────────
This is one of the most important ideas behind casting.

Consider:

Animal a = new Dog();

There are two types to understand:

Animal a = new Dog();
  │             │
  │             └── Actual object type
  │
  └── Reference type

# Reference Type: Determines which members can be accessed through the reference.

# Actual Object Type: Determines which overridden instance method executes at runtime.

Reference Type
      ↓
Accessible members
Actual Object Type
      ↓
Runtime method dispatch
────────────────────────────────────────────────────────────
17. Common Mistake
────────────────────────────────────────────────────────────
❌ Incorrect Assumption

Animal a = new Dog();
a.bark();

This does not compile if bark() exists only in Dog.

Why?

Reference type = Animal

and Animal does not declare bark().

Correct Approach

Dog d = (Dog) a;
d.bark();

19. Easy Way to Remember
────────────────────────────────────────────────────────────
             UPCASTING
        Child → Parent
              ↑
        Moving UP
        Usually automatic
            DOWNCASTING
        Parent → Child
              ↓
       Moving DOWN
        Explicit cast

Example

Dog d = new Dog();
// UP
Animal a = d;
// DOWN
Dog d2 = (Dog) a;

22. Key Points to Remember
────────────────────────────────────────────────────────────
# 5. Upcasting is commonly used to achieve runtime polymorphism.
# 6. Downcasting should be performed only when the actual object is compatible with the target child type.
