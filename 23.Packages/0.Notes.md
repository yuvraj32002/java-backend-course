============================================================
                    PACKAGES IN JAVA
============================================================
1. WHAT IS A PACKAGE?
---------------------
A package in Java is used to group related:

• Classes
• Interfaces
• Enums
• Sub-packages

Packages help to:

• Organize code
• Avoid naming conflicts
• Control access
• Improve code reusability
• Make large applications easier to maintain

Simple idea:

Related Classes
      ↓
   Package
      ↓
Organized Code


Example:
java.util
   |
   |---- ArrayList
   |---- LinkedList
   |---- Vector
   |---- Scanner
   |---- Random
============================================================
2. TYPES OF PACKAGES IN JAVA
============================================================
Java packages are mainly divided into two types:

                    PACKAGES
                       |
             +---------+---------+
             |                   |
       Built-in Packages   User-defined Packages
             |                   |
      Provided by Java       Created by Programmer

1. Built-in Packages
   → Provided by Java API
2. User-defined Packages
   → Created by programmers
============================================================
3. BUILT-IN PACKAGES
============================================================
Built-in packages are packages already provided by Java.
They contain classes and interfaces required for common
programming tasks.

Common Built-in Packages:
------------------------------------------------------------
1. java.lang
------------------------------------------------------------
Contains classes that provide fundamental language support.

Examples:

• String
• Math
• System
• Object
• Integer

# IMPORTANT: java.lang is automatically imported by Java. Therefore, we can directly use: String name = "Yuvraj";
# instead of: java.lang.String name = "Yuvraj";
------------------------------------------------------------
2. java.io
------------------------------------------------------------
# Used for Input/Output operations. It contains classes used for:

• Reading data
• Writing data
• File handling
• Input/Output streams
------------------------------------------------------------
3. java.util
------------------------------------------------------------
# Contains utility classes and commonly used data structures.

Examples:
• ArrayList
• LinkedList
• Vector
• HashMap
• HashSet
• Scanner
• Random
------------------------------------------------------------
4. java.awt
------------------------------------------------------------
# AWT = Abstract Window Toolkit

Used to create Graphical User Interfaces (GUI).
It contains components such as:

• Button
• Menu
• Frame
• Checkbox

============================================================
4. EXAMPLE OF BUILT-IN PACKAGE
============================================================
Example using java.util.Random:

import java.util.Random;
public class Main {

    public static void main(String[] args) {

        Random rand = new Random();

        int number = rand.nextInt(100);
        System.out.println(number);
    }
}
Here: import java.util.Random;

means:

java.util → Package
Random    → Class

nextInt(100) generates a random integer from: 0 to 99
Flow:
java.util
    ↓
 Random
    ↓
new Random()
    ↓
nextInt(100)
============================================================
5. USER-DEFINED PACKAGES
============================================================
User-defined packages are packages created by programmers.
# They are used to organize application-specific classes and interfaces.

Example:
package com.myapp;

public class Helper {
    public static void show() {
        System.out.println("Hello from Helper!");
    }
}

Here:
com.myapp → User-defined package
Helper    → Class
============================================================
6. USING A USER-DEFINED PACKAGE
============================================================
Suppose we have:

package com.myapp;
public class Helper {
    public static void show() {
        System.out.println("Hello from Helper!");
    }
}

Now another class can use Helper:

import com.myapp.Helper;
public class Test {
    public static void main(String[] args) {
        Helper.show();
    }
}


Output:
Hello from Helper!

Flow:
com.myapp
    ↓
  Helper
    ↓
 import
    ↓
  Test
    ↓
Helper.show()

============================================================
7. PACKAGE DECLARATION
============================================================
# The package keyword is used to specify the package to which a class belongs.

# Syntax: package packageName;
# Example: package com.myapp;

# The package declaration normally appears at the beginning of the Java source file.

Example:
package com.myapp;
public class Helper {
    void show() {
        System.out.println("Hello");
    }
}

Here:
package com.myapp;
declares that Helper belongs to the com.myapp package.
============================================================
8. FOLDER / DIRECTORY STRUCTURE
============================================================
# The directory structure normally follows the package name.

Example:
package com.myapp;

Folder structure:
com
 |
 └── myapp
      |
      └── Helper.java


Another example:
package com.company.project;

Folder structure:
com
 |
 └── company
      |
      └── project
           |
           └── ClassName.java
# IMPORTANT: Package name → Usually corresponds to folder structure.
============================================================
9. IMPORTING CLASSES FROM A PACKAGE
============================================================
# We can access classes from a package using the import keyword.
There are two common ways:

1. Import a single class
2. Import all classes
============================================================
10. IMPORTING A SINGLE CLASS
============================================================
# Syntax: import packageName.ClassName;

Example: import java.util.Vector;
This imports only the Vector class from java.util.

Now we can directly write:
Vector v = new Vector();

Instead of: java.util.Vector v = new java.util.Vector();
============================================================
11. IMPORTING ALL CLASSES
============================================================
# Syntax:mimport packageName.*;

Example: import java.util.*;
This imports all accessible classes and interfaces from java.util.

Example:
import java.util.*;
public class Main {
    public static void main(String[] args) {

        ArrayList<Integer> list = new ArrayList<>();

        list.add(10);
        list.add(20);

        System.out.println(list);
    }
}
# IMPORTANT:
# * means: "All classes/interfaces directly inside this package"
# It does NOT import classes from sub-packages.

Example:

import java.util.*;
does NOT automatically import:
java.util.concurrent.*
============================================================
13. FULLY QUALIFIED CLASS NAME
============================================================
# We can use a class without importing it by using its fully qualified name.


Example:

java.util.ArrayList<Integer> list =
        new java.util.ArrayList<>();


Here:

java.util.ArrayList

is the fully qualified name.


Structure:

Package Name
     +
Class Name
     ↓
Fully Qualified Class Name


Example:

java.util.ArrayList


java → Top-level package
util → Sub-package
ArrayList → Class


============================================================
14. IMPORT vs FULLY QUALIFIED NAME
============================================================

Using import:

import java.util.ArrayList;

ArrayList<Integer> list =
        new ArrayList<>();


Using fully qualified name:

java.util.ArrayList<Integer> list =
        new java.util.ArrayList<>();


Difference:

import
  ↓
Shorter and cleaner code


Fully Qualified Name
  ↓
No import required


============================================================
15. EXAMPLE: IMPORT AND FULLY QUALIFIED NAME
============================================================

import java.util.Vector;

public class Geeks {

    public static void main(String[] args) {

        Vector v = new Vector();

        java.util.ArrayList<Integer> list =
                new java.util.ArrayList<>();

        list.add(3);
        list.add(5);
        list.add(7);

        System.out.println(list);
    }
}


Output:

[3, 5, 7]


Explanation:

Vector is imported:

import java.util.Vector;

Therefore we can directly write:

Vector v = new Vector();


But ArrayList is not imported.

Therefore we use:

java.util.ArrayList


which is its fully qualified name.

16. PACKAGES AND ACCESS CONTROL
============================================================

Packages are also important for access control.

Java provides four access levels:

                    ACCESS MODIFIERS
                           |
        +----------+-------+-------+----------+
        |          |               |          |
      private   default        protected    public


Package plays an important role in determining where a
class/member can be accessed.


IMPORTANT:

• private → accessible only inside the same class
• default → accessible within the same package
• protected → accessible within same package + subclasses
• public → accessible from anywhere


Quick view:

                    Same     Same     Subclass   Other
                    Class    Package  Outside    Package

private               ✓         ✗         ✗          ✗

default                ✓         ✓         ✗          ✗

protected              ✓         ✓         ✓          ✓*
 
public                 ✓         ✓         ✓          ✓


* protected access outside the package is allowed through
  inheritance/subclass relationship.

17. ADVANTAGES OF PACKAGES
============================================================

1. ORGANIZATION
---------------

Packages organize related classes and interfaces together.


2. AVOID NAMING CONFLICTS
-------------------------

Different packages can contain classes with the same name.


Example:

package package1;
class Student { }


package package2;
class Student { }


Both can exist because they belong to different packages.


3. ACCESS CONTROL
-----------------

Packages work with access modifiers to control access
to classes and members.


4. CODE MAINTAINABILITY
-----------------------

Packages make large projects easier to organize,
understand and maintain.


5. CODE REUSABILITY
-------------------

Classes inside packages can be reused in different parts
of an application.


6. MODULAR DESIGN
-----------------

Packages help divide a large application into smaller,
logical modules.

============================================================
19. PACKAGE vs IMPORT
============================================================

package
   ↓
Tells Java:
"Which package does this class belong to?"


import
   ↓
Tells Java:
"Which class/package do I want to use?"


Example:

package myapp;

import java.util.Scanner;


Here:

package myapp;
→ Declares the current package.


import java.util.Scanner;
→ Imports Scanner from java.util.
