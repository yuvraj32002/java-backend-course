INHERITANCE IN JAVA
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. WHAT IS INHERITANCE?

Inheritance is an OOP concept in which one class acquires the properties and methods of another class.

It is mainly used for:

→ Code Reusability
→ Method Overriding
→ Runtime Polymorphism
→ Creating Class Hierarchies
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
2. WHY DO WE NEED INHERITANCE?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Suppose we have:

class Car {
    void start() {
        System.out.println("Vehicle starts");
    }
}
class Bike {
    void start() {
        System.out.println("Vehicle starts");
    }
}

Here, the same start() method is written multiple times.

With inheritance:

class Vehicle {
    void start() {
        System.out.println("Vehicle starts");
    }
}
class Car extends Vehicle {
}
class Bike extends Vehicle {
}

Now both Car and Bike can use start().

# Main Idea: Write Once → Reuse Multiple Times
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
3. SYNTAX OF INHERITANCE

class Parent {
    // fields
    // methods
}
class Child extends Parent {
    // additional fields
    // additional methods
}

# Important:extends is used when one class inherits another class.
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
4. IMPORTANT TERMINOLOGIES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
->Superclass / Parent Class: The class whose properties and methods are inherited.

->Subclass / Child Class: The class that inherits properties and methods from another class.

->extends: Keyword used to establish inheritance between classes.
Example:
class Animal {
}
class Dog extends Animal {
}
Animal
   ↑
   |
  Dog

Animal → Superclass
Dog → Subclass
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
5. SIMPLE EXAMPLE OF INHERITANCE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
class Animal {
    void eat() {
        System.out.println("Animal eats");
    }
}
class Dog extends Animal {
    void bark() {
        System.out.println("Dog barks");
    }
}
class Main {
    public static void main(String[] args) {
        Dog d = new Dog();
        d.eat();     // inherited method
        d.bark();    // Dog's own method
    }
}
Output:

Animal eats
Dog barks

Explanation: Dog inherits eat() from Animal.

Therefore: d.eat();
works even though eat() is not written inside Dog.
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
6. TYPES OF INHERITANCE IN JAVA
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Java supports the following forms of inheritance:
1. Single Inheritance
2. Multilevel Inheritance
3. Hierarchical Inheritance
4. Multiple Inheritance → Through Interfaces
5. Hybrid Inheritance → Through Interfaces
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
7. SINGLE INHERITANCE:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
In Single Inheritance, one subclass inherits from one superclass.

Structure:
Parent
  |
  ↓
Child

Example:

class Vehicle {
    void start() {
        System.out.println("Vehicle starts");
    }
}
class Car extends Vehicle {
    void drive() {
        System.out.println("Car is driving");
    }
}
Vehicle
   ↑
   |
  Car

Car inherits from Vehicle.
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
8. MULTILEVEL INHERITANCE:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
In Multilevel Inheritance, a class inherits from another class, and that class is further inherited by another class.

Structure:

Grandparent
     |
     ↓
   Parent
     |
     ↓
    Child

Example:

class Vehicle {
    void vehicleType() {
        System.out.println("Vehicle");
    }
}
class Car extends Vehicle {
    void carType() {
        System.out.println("Car");
    }
}
class SportsCar extends Car {
    void sportsCarType() {
        System.out.println("Sports Car");
    }
}

Structure:

Vehicle
   ↑
  Car
   ↑
SportsCar

# SportsCar can access methods of:
# → Car
# → Vehicle
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
9. HIERARCHICAL INHERITANCE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
In Hierarchical Inheritance, multiple subclasses inherit from the same superclass.

Structure:

        Parent
        /     \
       ↓       ↓
    Child1   Child2

Example:

class Vehicle {
    void start() {
        System.out.println("Vehicle starts");
    }
}
class Car extends Vehicle {
    void carType() {
        System.out.println("Car");
    }
}
class Bus extends Vehicle {
    void busType() {
        System.out.println("Bus");
    }
}
Structure:

        Vehicle
        /     \
       ↓       ↓
     Car      Bus

Both Car and Bus inherit start() from Vehicle.
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
10. MULTIPLE INHERITANCE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
# Multiple Inheritance means:
# One class inherits from more than one parent class.

Structure:

 Parent 1      Parent 2
     \          /
      \        /
       \      /
        Child

# Java does not support Multiple Inheritance using classes.
# Because, it can create ambiguity when both parent classes contain methods with the same name.
# This problem is commonly known as the Diamond Problem.
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
11. MULTIPLE INHERITANCE THROUGH INTERFACES:-
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
# Java can achieve multiple inheritance using interfaces.
Example:

interface LandVehicle {
    default void landInfo() {
        System.out.println("Land Vehicle");
    }
}
interface WaterVehicle {
    default void waterInfo() {
        System.out.println("Water Vehicle");
    }
}
class AmphibiousVehicle implements LandVehicle, WaterVehicle {
}
# In Modern Java interfaces can contain methods with a body.
Structure:

LandVehicle --------\
                     \
                      → AmphibiousVehicle
                     /
WaterVehicle -------/

# The class implements both interfaces.
Therefore:

AmphibiousVehicle obj = new AmphibiousVehicle();
obj.landInfo();
obj.waterInfo();
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
12. HYBRID INHERITANCE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
# Hybrid Inheritance is a combination of two or more types of inheritance.

Java does not support hybrid inheritance using classes alone.

It can be achieved using interfaces along with class inheritance.

Example:

class Vehicle {
    void vehicleType() {
        System.out.println("Vehicle");
    }
}
interface Fare {
    default void fareInfo() {
        System.out.println("Fare Information");
    }
}
class Bus extends Vehicle implements Fare {
    void busType() {
        System.out.println("Bus");
    }
}

Here Bus:

→ Extends Vehicle
→ Implements Fare

So, Bus gets functionality from both a class and an interface.
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
13. IS-A RELATIONSHIP
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
# Inheritance represents an IS-A relationship.
It means: A child object is a type of its parent.

Example:
class Animal {
}
class Dog extends Animal {
}

# Therefore: Dog IS-A Animal
# Remember: IS-A  → Inheritance
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
14. WHAT CAN A SUBCLASS DO?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
A subclass can:

1. Use inherited fields

class Parent {
    int x = 10;
}
class Child extends Parent {
}

Child can access x.
⸻
2. Add new fields

class Child extends Parent {
    int y = 20;
}
⸻
3. Use inherited methods

class Parent {
    void show() {
        System.out.println("Parent");
    }
}
class Child extends Parent {
}
Now:
Child obj = new Child();
obj.show();
⸻
4. Override inherited methods

class Animal {
    void sound() {
        System.out.println("Animal sound");
    }
}
class Dog extends Animal {
    @Override
    void sound() {
        System.out.println("Dog barks");
    }
}
This is called Method Overriding.
⸻
5. Add new methods
class Dog extends Animal {
    void bark() {
        System.out.println("Dog barks");
    }
}
⸻
6. Call Parent Constructor

# A subclass can call the parent constructor using: super();
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
15. CONSTRUCTOR EXECUTION IN INHERITANCE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
# When an object of a child class is created: Dog d = new Dog();
# the parent constructor executes before the child constructor.

Example:
class Animal {
    Animal() {
        System.out.println("Animal");
    }
}
class Dog extends Animal {
    Dog() {
        System.out.println("Dog");
    }
}

Output:
Animal
Dog

Order   Object Creation
            ↓
        Parent Constructor
            ↓
        Child Constructor

# Remember: Parent Constructor → Child Constructor
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
16. INHERITANCE + METHOD OVERRIDING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
# Inheritance is closely related to Runtime Polymorphism.

Example:

class Animal {
    void sound() {
        System.out.println("Animal sound");
    }
}
class Dog extends Animal {
    @Override
    void sound() {
        System.out.println("Dog barks");
    }
}
# Animal a = new Dog();
# a.sound();

# Output: Dog barks

Altough:    Reference Type → Animal
            Object Type    → Dog
# the overridden method of Dog is executed at runtime.

Flow:
Animal a = new Dog();
        ↓
Reference → Animal
Object    → Dog
        ↓
a.sound()
        ↓
Dog's sound()

This is called Runtime Polymorphism.
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

18. ADVANTAGES OF INHERITANCE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Code Reusability

2. Less Code Duplication :Common fields and methods can be placed in the parent class.
3. Supports Polymorphism: Inheritance enables method overriding and runtime polymorphism.
4. Easy Maintenance: Common functionality can be maintained in one superclass.
5. Class Hierarchy: It helps represent relationships between related classes.

Example:

          Animal
        /    |    \
       ↓     ↓     ↓
     Dog    Cat    Cow

19. LIMITATIONS OF INHERITANCE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Tight Coupling: The subclass is strongly dependent on the superclass. Changes in the superclass may affect subclasses.

2. Complex Hierarchies: Very deep inheritance structures can become difficult to understand.

3. Less Flexibility: In some situations, Composition is more flexible than inheritance.

Represents: HAS-A

Example:
Car HAS-A Engine

            IS-A  → Inheritance
