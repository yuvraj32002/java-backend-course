1. What is StringBuffer?
-------------------------------------------------
* StringBuffer is a class used to create a mutable sequence of characters.
* Mutable → Its content can be changed after the object is created.
* It is thread-safe because its methods are synchronized.
* It is mainly used when a string needs frequent modifications.
-------------------------------------------------
2. Why StringBuffer?
-------------------------------------------------
String
  ↓
Immutable
  ↓
Modification creates a new String object
-------------------------------------------------
StringBuffer
  ↓
Mutable
  ↓
Existing object can be modified

So, StringBuffer is useful when we perform operations like:

append → insert → replace → delete → reverse
-------------------------------------------------
3. Creating StringBuffer
-------------------------------------------------
# StringBuffer sb = new StringBuffer("Hello");
An empty StringBuffer can also be created:

# StringBuffer sb = new StringBuffer();
# Default Capacity: 16 characters

For: StringBuffer sb = new StringBuffer("Hello");
# Initial capacity: String length + 16
= 5 + 16
= 21
-------------------------------------------------
4. Important StringBuffer Methods
-------------------------------------------------
# 3. replace() Replaces characters from (start) to (end - 1).
-------------------------------------------------
# Syntax: sb.replace(start, end, newString);

Example

StringBuffer sb = new StringBuffer("Hello");
sb.replace(1, 3, "i");
System.out.println(sb);

Output:

Hilo

Important: start → included
           end   → excluded

6. toString()
-------------------------------------------------

Converts a StringBuffer into a String.

Syntax
String str = sb.toString();

Example
StringBuffer sb = new StringBuffer("Hello");
String str = sb.toString();
System.out.println(str);

Output:

Hello

Why is it used?

When a method or operation requires a String instead of a StringBuffer.

8. Exam Points
-------------------------------------------------
• StringBuffer is mutable.
• StringBuffer is thread-safe.
• Its methods are synchronized.
• Default capacity is 16.
• StringBuilder is generally preferred over StringBuffer
  when thread safety is not required.

StringBuilder in Java
-------------------------------------------------
What is StringBuilder?

* StringBuilder is a mutable sequence of characters.
* It is used for frequent string modifications.
# * It is not thread-safe because its methods are not synchronized.
# * It is generally faster than StringBuffer in single-threaded programs.

StringBuilder sb = new StringBuilder("Hello");
sb.append(" Java");
System.out.println(sb);

Output:

Hello Java
