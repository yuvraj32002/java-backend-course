FINAL KEYWORD IN JAVA
-----------------------------------
1. What is final?

final is a keyword used to restrict modification.

final variable → Cannot be reassigned
final method   → Cannot be overridden
final class    → Cannot be inherited

-----------------------------------
2. final Variable
-----------------------------------
A final variable can be assigned only once.

final int x = 10;
x = 20;       // ❌ Error

# Blank final variable: Can be initialized later, but only once.

final int x;
x = 10;       // ✅
x = 20;       // ❌

-----------------------------------
3. final Reference
-----------------------------------
# final prevents the reference from changing, not necessarily the object.

final StringBuilder sb = new StringBuilder("Hello");
sb.append(" Java");              // ✅
sb = new StringBuilder("World"); // ❌
Reference cannot change
        ↓
Object may still be modified

-----------------------------------
4. final Method
-----------------------------------
# A final method cannot be overridden.

class Parent {
    final void show() {
        System.out.println("Hello");
    }
}
class Child extends Parent {
    // void show() { }     // ❌ Cannot override
}

Important

# final method → Can be inherited ✅ but, Cannot be overridden ❌
-----------------------------------
5. final Class
-----------------------------------
# A final class cannot be inherited.

final class Parent {
}
class Child extends Parent {   // ❌ Error
}
-----------------------------------
6. static final
-----------------------------------
# static final is commonly used to create constants.

class MathConstants {
    static final double PI = 3.14159;
}
# static → Shared by the class
# final  → Cannot be reassigned

# Convention: constants are written in UPPERCASE.

-----------------------------------
7. Quick Comparison
-----------------------------------
final Applied To	|Effect
---------------------------------------------
Variable	        |Cannot be reassigned
Method	            |Cannot be overridden
Class	            |Cannot be inherited
----------------------------------------------
8. Important Points
-----------------------------------
1. final variable → Assign only once.
2. final method → Cannot be overridden.
3. final class → Cannot be extended or inherited;
4. final method can still be inherited.
5. final reference ≠ immutable object,it only means the the reference cannot be changed.
6. static final → Commonly used for constants.

Memory Trick
-----------------------------------
VARIABLE → Value fixed
METHOD   → Overriding blocked
CLASS    → Inheritance blocked
