LOCAL REPOSITORY → REMOTE REPOSITORY → PUSH
=================================================
Prerequisite:
SSH authentication is already completed.
SSH authentication test:
ssh -T git@github.com
If authentication is successful, GitHub shows:
Hi USERNAME! You've successfully authenticated,
but GitHub does not provide shell access.
=================================================
STEP 1: CREATE / ENTER PROJECT FOLDER
=================================================
Create a project folder: mkdir git-course
Enter the folder: cd git-course
Check current files: ls
=================================================
STEP 2: CREATE PROJECT FILE
=================================================
Example: echo "git-course demo" >> README.md
Read the file: cat README.md
Output: git-course demo
=================================================
STEP 3: INITIALIZE GIT
=================================================
Command: git init
Purpose: Converts the normal project folder into a Git repository.
It creates a hidden .git folder.
Check hidden files: ls -a
Example:
.
..
.git
README.md
=================================================
STEP 4: CHECK GIT STATUS
=================================================
Command: git status
Purpose: Shows the current state of the Git repository.
It tells you:
- Modified files
- Untracked files
- Staged files
- Current branch
=================================================
STEP 5: STAGE FILES
=================================================
Command: git add .
Purpose: Moves all current changes into the staging area.
Flow:
Working Directory
       ↓
   git add .
       ↓
Staging Area
=================================================
STEP 6: CREATE COMMIT
=================================================
Command: git commit -m "Initial commit"
Purpose: Creates a saved version/checkpoint of the staged changes in local repository.
Flow:
Working Directory
       ↓
   git add .
       ↓
Staging Area
       ↓
git commit
       ↓
Git Repository(local)
=================================================
STEP 7: RENAME BRANCH TO MAIN
=================================================
Command: git branch -M main
Purpose: Renames the current branch to "main".
Check current branch: git branch
Example:
* main
=================================================
STEP 8: CREATE REMOTE REPOSITORY
=================================================
Go to GitHub and create a new repository.
Example:
GitHub
└── git-course
Important:
Do NOT need to run git init again for the GitHub repository.
=================================================
STEP 9: CONNECT LOCAL REPO TO REMOTE REPO
=================================================
# SSH remote URL format: git remote add origin git@github.com:USERNAME/REPOSITORY.git

Example: git remote add origin git@github.com:yuvraj32002/git-course.git

Meaning: git remote add
→ Add a remote repository
origin
→ Name/nickname of the remote
git@github.com:...
→ SSH address of the GitHub repository
=================================================
STEP 10: CHECK REMOTE CONNECTION
=================================================
# Command: git remote -v
Expected output:
origin  git@github.com:yuvraj32002/git-course.git (fetch)
origin  git@github.com:yuvraj32002/git-course.git (push)
Meaning:
fetch
→ URL used to get data from GitHub
push
→ URL used to send data to GitHub
=================================================
STEP 11: PUSH LOCAL REPOSITORY TO GITHUB
=================================================
# Command: git push -u origin main
Meaning:
git push
→ Send local commits to remote
origin
→ Remote repository
main
→ Branch where commits should be pushed
-u
→ Set upstream tracking between local main
   and remote origin/main
After the first push:
git push
is usually enough.
=================================================
COMPLETE PRACTICAL COMMAND FLOW
=================================================
mkdir git-course
cd git-course
echo "git-course demo" >> README.md
cat README.md
git init
ls -a
git status
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin git@github.com:yuvraj32002/git-course.git
git remote -v
git push -u origin main
After the first push:
git add .
git commit -m "Your message"
git push

=================================================
IMPORTANT TERMS
=================================================
LOCAL REPOSITORY
→ Git repository stored on your computer.
REMOTE REPOSITORY
→ Git repository stored on GitHub.
ORIGIN
→ Nickname given to the remote repository.
MAIN
→ Name of the main branch.
COMMIT
→ Saved version/checkpoint of changes.
STAGING AREA
→ Area where changes are prepared before committing.
PUSH
→ Send local commits to the remote repository.
FETCH
→ Get information/changes from the remote repository
   without applying them to your working files.
=================================================
IMPORTANT DISTINCTION
=================================================
SSH AUTHENTICATION
→ "Who are you?"
REMOTE CONNECTION
→ "Which GitHub repository are we connecting to?"
PUSH
→ "Send my local commits to that repository."
=================================================
FOR A NEW PROJECT AFTER SSH IS ALREADY SET UP
=================================================

git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin git@github.com:USERNAME/REPOSITORY.git
git push -u origin main
After the first push:
git add .
git commit -m "Your message"
git push
