JAVA CLASSES & OBJECTS — COMPLETE NOTES
=======================================

1. CLASS IN JAVA
----------------

Definition:
A class is a user-defined data type that acts as a blueprint/template for creating objects.

A class groups:
1. Data → fields/variables
2. Behavior → methods
3. Object initialization → constructors
4. It can also contain nested classes and interfaces.

CLASS = Blueprint
OBJECT = Actual thing created from the blueprint

2. OBJECT IN JAVA
-----------------
Definition:
An object is an instance of a class.

3. THREE IMPORTANT CHARACTERISTICS OF AN OBJECT
------------------------------------------------
An object has:-
1. STATE
2. BEHAVIOR
3. IDENTITY

3.1 STATE
State means the data/values currently stored inside an object.

3.2 BEHAVIOR
Behavior means what an object can do.
Behavior is represented using methods.

3.3 IDENTITY
Identity distinguishes one object from another.

Example:

Dog d1 = new Dog();
Dog d2 = new Dog();

Even though both are Dog objects:

d1 → Object A
d2 → Object B

They are two separate objects.


5. OBJECT INSTANTIATION
-----------------------
Instantiation means creating an object of a class.

Example:

Dog d1 = new Dog();

Breakdown:

Dog d1 = new Dog();
 |   |      |
 |   |      └── Object creation
 |   └───────── Reference variable
 └───────────── Reference type


6. DECLARATION VS OBJECT CREATION
----------------------------------

6.1 DECLARATION

Example:

Dog d1;

Here, only a reference variable is declared.

No Dog object has been created yet.

Conceptually:

d1 → null


6.2 OBJECT CREATION / INITIALIZATION

Example:

d1 = new Dog();

Now an object is created and d1 refers to it.

Conceptually:

Stack                Heap

d1  ─────────────→   Dog object


Combined:

Dog d1 = new Dog();

This combines:
1. Declaration of reference variable
2. Object creation
3. Assignment of reference


7. WHAT DOES new DO?
--------------------
The new keyword is used to create an object.

new
 ↓
Create object
 ↓
Allocate memory for object
 ↓
Constructor executes
 ↓
Reference to object is obtained
 ↓
Reference is stored in d1


8. CONSTRUCTOR AND OBJECT CREATION
----------------------------------

Example:

class Student {

    int id;
    String name;

    Student(int id, String name) {
        this.id = id;
        this.name = name;
    }
}

Creating object:

Student s1 = new Student(101, "Yuvraj");

Conceptually:

new Student(101, "Yuvraj")
            |
            ↓
      Constructor called
            |
            ↓
      Student object created
            |
            ↓
    ---------------------
    | id   = 101         |
    | name = "Yuvraj"    |
    ---------------------
            ↑
            |
           s1

11. WHY DO OBJECTS HAVE SEPARATE STATE?
---------------------------------------

Example:

Student s1 = new Student(101, "Yuvraj");
Student s2 = new Student(102, "Rahul");

s1.name = "Amit";

Only s1 changes.

State:

s1 → name = Amit
s2 → name = Rahul

Reason:

s1 and s2 refer to two different objects.


12. GETTER AND SETTER METHODS
-----------------------------

Getter:
Used to retrieve/read a value.

Example:

public String getName() {
    return name;
}


Setter:
Used to modify/change a value.

Example:

public void setName(String name) {
    this.name = name;
}

Example:

Product p1 = new Product("Laptop", 50000);

System.out.println(p1.getName());

p1.setName("MacBook");

# Getters and setters are commonly used with encapsulation.


13. this KEYWORD
----------------
# The this keyword refers to the current object.

Example:

class Student {

    int id;
    String name;

    Student(int id, String name) {
        this.id = id;
        this.name = name;
    }
}

Here:

# this.id → instance variable of current object
# id     → constructor parameter

14.  System.out.println(object)
------------------------------
Suppose:

Dog d = new Dog("Tommy");

# System.out.println(d);

d is an object reference.

# When an object is passed to println(), Java obtains its string
# representation through toString().

Example:

@Override
public String toString() {
    return "Dog: " + name;
}

Then:

System.out.println(d);

Output:

Dog: Tommy


# INTERNAL FLOW:

System.out.println(d)
          ↓
Object needs String representation
          ↓
toString()
          ↓
Overridden toString()
          ↓
"Dog: Tommy"
          ↓
Printed


IMPORTANT:

For objects, println() can use the object's toString() representation.

# If toString() is not overridden, the inherited Object.toString() implementation is used, which normally produces a class-name/hash-based representation.

16. WAYS TO CREATE/RECREATE OBJECTS IN JAVA
--------------------------------------------
Common approaches include:
1. new keyword
2. Reflection
3. clone()
4. Deserialization

16.1 new KEYWORD
----------------
Most common method:

Student s = new Student();

# The new keyword creates a new object and invokes the constructor.


16.2 REFLECTION
---------------
# Reflection allows classes and constructors to be accessed dynamically at runtime.

Example:

Class<?> c = Class.forName("Student");

Student s =
    (Student) c.getDeclaredConstructor().newInstance();

Conceptual flow:

Class name
    ↓
Reflection
    ↓
Find class
    ↓
Find constructor
    ↓
Create object


16.3 clone()
------------

clone() can create another object based on an existing object.

Example:

Student s1 = new Student();

Student s2 = (Student) s1.clone();

Conceptually:

s1
 ↓
Object A
 ↓ clone()
Object B
 ↑
s2

Important:

clone() has important details such as:
- Cloneable interface
- clone() method
- Shallow copy
- Deep copy

These should be studied separately.


16.4 DESERIALIZATION
--------------------
Deserialization recreates an object from a previously serialized
representation.

Conceptual flow:

Object
  ↓
Serialization
  ↓
Byte stream / File
  ↓
Deserialization
  ↓
Object recreated

Common classes:

ObjectOutputStream
ObjectInputStream

This is object recreation from stored data rather than the normal new-object approach.

19. REFERENCE VS OBJECT
----------------------
This is one of the MOST IMPORTANT concepts.

Example:

Dog d = new Dog();

Do NOT simply think:

"d is the object."

More precisely:

d
|
|  reference
|
↓
+------------------+
|   Dog object     |
|                  |
|   name           |
|   age            |
+------------------+

Therefore:

# d        → Reference variable
# new Dog  → Actual object

# The reference variable stores a reference that allows us to access the object.

20. null
--------
Example:
Dog d;
# A local reference variable that has only been declared is not automatically initialized to null.

For example:

Dog d = null;

Here:

d → null

Meaning:

d currently does not refer to any Dog object.

Important:

# null is a special reference value meaning "no object is currently referred to."


21. STACK AND HEAP — BASIC CONCEPT
-----------------------------------

For basic understanding:

Dog d = new Dog();

Conceptually:

STACK                  HEAP

d ─────────────────→   Dog object
                       |
                       | name
                       | age
                       | ...


Important:

d is a reference variable.

The actual object is created in heap memory.

# The exact JVM memory model has additional details, but this model is sufficient for basic OOP understanding.

22. OBJECT IDENTITY
-------------------

Example:

Dog d1 = new Dog();
Dog d2 = new Dog();

Even if:

d1 and d2 have the same field values

they can still be two different objects.

Conceptually:

d1 ─────→ Object A

d2 ─────→ Object B

Object A ≠ Object B

23. OBJECT STATE
----------------
Instance variables belong to individual objects.

Example:

class Student {

    int id;
    String name;
}

Student s1 = new Student();
Student s2 = new Student();

s1.id = 101;
s2.id = 102;

Conceptually:

s1 → id = 101
s2 → id = 102

Each object maintains its own instance state.

24. COMPLETE OBJECT CREATION FLOW
---------------------------------
When we write:
Student s = new Student(101, "Yuvraj");
Conceptually:

1. Student is the reference type.
2. s is the reference variable.
3. new requests creation of a Student object.
4. Constructor is invoked.
5. Object is initialized.
6. A reference to that object is obtained.
7. s stores that reference.
8. We use s to access the object.

FLOW:

Student s = new Student(101, "Yuvraj");
       |
       ↓
Reference variable
       |
       ↓
new
       |
       ↓
Object creation
       |
       ↓
Constructor execution
       |
       ↓
Object initialized
       |
       ↓
s refers to object


25. QUICK REVISION — IMPORTANT TERMS
------------------------------------
Class
→ Blueprint/template for creating objects.

Object
→ Instance of a class.

Field
→ Variable representing data/state.

Method
→ Defines behavior/action.

Constructor
→ Special mechanism used during object creation/initialization.

new
→ Used to create a new object.

Reference variable
→ Variable that refers to an object.

Instantiation
→ Process of creating an object.

State
→ Current values stored in an object.

Behavior
→ Actions performed by an object through methods.

Identity
→ Distinguishes one object from another.

Getter
→ Method used to read/access a value.

Setter
→ Method used to modify a value.

this
→ Refers to the current object.

toString()
→ Provides a string representation of an object.

Anonymous object
→ Object created without storing its reference in a variable.

Reflection
→ Runtime mechanism for dynamically inspecting/accessing classes and creating objects.

clone()
→ Mechanism for creating a copy of an existing object.

Serialization
→ Converting an object's state into a storable/transmittable form.

Deserialization
→ Reconstructing an object from serialized data.
