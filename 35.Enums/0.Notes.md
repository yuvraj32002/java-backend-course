ENUM IN JAVA
------------------------------------
1. WHAT IS ENUM?

Enum (Enumeration) is a special Java type used to represent
a FIXED SET of named constants.

Example:

enum Day {
MONDAY, TUESDAY, WEDNESDAY, THURSDAY, FRIDAY
}

Day d = Day.MONDAY;

Benefits:
• Type-safe
• Readable
• Prevents invalid values
• Useful with switch
------------------------------------
2. ENUM CONSTANTS
------------------------------------
# Enum constants are implicitly: public static final

Example:

enum Color {
RED, GREEN, BLUE
}

Each constant is an OBJECT of the enum type.

Color.RED → object of Color
------------------------------------
3. ENUM METHODS
------------------------------------
For:

enum Color {
RED, GREEN, BLUE
}

# values() → Returns all constants.
# Color.values();

# valueOf(String) → Converts String → enum constant.
# Color.valueOf(“RED”);

# ordinal() → Returns zero-based position.
# Color.GREEN.ordinal();    // 1

# name() → Returns exact declared name.
# Color.RED.name();         // “RED”

# toString()
# → Returns String representation.
# → Can be overridden.

# compareTo() → Compares constants according to declaration order.
------------------------------------
4. ENUM WITH switch
------------------------------------
enum Color {
RED, GREEN, BLUE
}

Color c = Color.RED;

switch (c) {

case RED:
    System.out.println("Red");
    break;
case GREEN:
    System.out.println("Green");
    break;
case BLUE:
    System.out.println("Blue");

}
------------------------------------
5. ENUM CONSTRUCTOR + VARIABLES
------------------------------------
# Enum can have fields and constructors.

enum Status {

SUCCESS(200),
FAILED(500);
private int code;
Status(int code) {
    this.code = code;
}
public int getCode() {
    return code;
}

}

Usage:

Status.SUCCESS.getCode();     // 200

IMPORTANT:
• Constructor is called automatically.
• Cannot create enum object using new.

new Status(200);   // ERROR
------------------------------------
6. ENUM WITH METHODS
------------------------------------
enum Day {

MONDAY,
FRIDAY;
void display() {
    System.out.println(this);
}

}

Day.MONDAY.display();

7. ENUM WITH ABSTRACT METHOD

Each constant can have its own implementation.

enum Operation {

ADD {
    public int calculate(int a, int b) {
        return a + b;
    }
},
SUBTRACT {
    public int calculate(int a, int b) {
        return a - b;
    }
};
public abstract int calculate(int a, int b);

}

⸻

8. ENUM + INTERFACE

Enum cannot extend another class, but it CAN implement
interfaces.

interface Printable {
void print();
}

enum Color implements Printable {

RED, GREEN;
public void print() {
    System.out.println(this);
}

}

⸻

9. ENUM INHERITANCE

Every enum implicitly extends:

java.lang.Enum

Therefore:

enum Color extends Something    // ❌ NOT allowed

enum Color implements Interface // ✅ allowed

Hierarchy:

Object
↓
java.lang.Enum
↓
Color
↓
RED, GREEN, BLUE

⸻

10. ENUM vs CONSTANTS

Normal constants:

class Status {
public static final int SUCCESS = 1;
public static final int FAILED = 2;
}

Problem:

int s = 100;    // Valid

Enum:

enum Status {
SUCCESS, FAILED
}

Status s = Status.SUCCESS;

Only valid Status values can be assigned.

→ ENUM provides TYPE SAFETY.

⸻

11. ENUM vs STRING

String:

String status = “SUCCESS”;

Can contain any value.

Enum:

Status status = Status.SUCCESS;

Only predefined values are allowed.

⸻

12. IMPORTANT ENUM RULES

✓ Can have fields
✓ Can have constructors
✓ Can have methods
✓ Can have abstract methods
✓ Can implement interfaces
✓ Works with switch
✓ Constants are objects
✓ Constants are public static final

✗ Cannot use new
✗ Cannot extend another class
✗ Cannot declare enum inside a method

⸻

13. IMPORTANT INTERVIEW QUESTIONS

Q. What is enum?
→ A special type for representing a fixed set of constants.

Q. Can enum have constructor?
→ Yes, but it is called automatically.

Q. Can enum have methods?
→ Yes.

Q. Can enum implement interface?
→ Yes.

Q. Can enum extend a class?
→ No. It already extends java.lang.Enum.

Q. Can we create enum object using new?
→ No.

Q. Are enum constants objects?
→ Yes.

Q. What does ordinal() return?
→ Zero-based position.

Q. What does values() return?
→ All enum constants.

Q. What does valueOf() do?
→ Converts String to enum constant.

Q. Is valueOf() case-sensitive?
→ Yes.

Q. Can toString() be overridden?
→ Yes.

Q. Can name() be overridden?
→ No.
