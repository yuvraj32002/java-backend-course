Java String Methods:-
----------------------------------------------------------------
1. length()
----------------------------------------------------------------
→ Returns the number of characters present in a String.

Syntax:
str.length();

Example:

String str = "Hello";
System.out.println(str.length());

Output:
5

Remember:
Last Index = length - 1
----------------------------------------------------------------
2. charAt()
----------------------------------------------------------------
→ Returns the character present at a particular index.

Syntax:
str.charAt(index);

Example:

String str = "Hello";
System.out.println(str.charAt(1));

Output:
e

Indexing:

H   e   l   l   o
0   1   2   3   4

→ Return type: char
----------------------------------------------------------------
3. substring()
----------------------------------------------------------------
→ Used to extract a part of a String.

a) substring(startIndex)
-------------------------
# → Returns characters from startIndex to the end.

Example:

String str = "Hello World";
System.out.println(str.substring(6));

Output:
World

b) substring(startIndex, endIndex)
------------------------------------
# → Returns characters from startIndex to (endIndex - 1).

Example:

String str = "Hello World";
System.out.println(str.substring(0, 5));

Output:
Hello

Important:

# startIndex → Included,  endIndex   → Excluded
----------------------------------------------------------------
4. concat()
----------------------------------------------------------------
→ Joins two Strings.
Syntax:
str1.concat(str2);

Example:

String str1 = "Hello ";
String str2 = "Java";
System.out.println(str1.concat(str2));

Output:
Hello Java

# → Alternative: str1 + str2
----------------------------------------------------------------
5. indexOf()
----------------------------------------------------------------
# → Returns the index of the first occurrence of a character/String.

Example:

String str = "Hello";
System.out.println(str.indexOf("l"));

Output:
2

# → If the character/String is not found, it returns -1.
----------------------------------------------------------------
6. lastIndexOf()
----------------------------------------------------------------
→ Returns the index of the last occurrence of a character/String.

indexOf()       → First occurrence
lastIndexOf()   → Last occurrence
----------------------------------------------------------------
# 7. equals()->  Compares the contents of two Strings.
----------------------------------------------------------------
Example:

String str1 = "Java";
String str2 = "Java";
# System.out.println(str1.equals(str2));

Output:
true

Important:
# equals() → Content comparison, ==  → Reference comparison
----------------------------------------------------------------
8. equalsIgnoreCase()
----------------------------------------------------------------
# → Compares two Strings while ignoring uppercase/lowercase differences.

Example:

String str1 = "JAVA";
String str2 = "java";
System.out.println(str1.equalsIgnoreCase(str2));

Output:
true

# equals()            → Case-sensitive
# equalsIgnoreCase()  → Case-insensitive
----------------------------------------------------------------
9. compareTo()
----------------------------------------------------------------
# → Compares two Strings lexicographically (dictionary order).
Example:

String str1 = "Apple";
String str2 = "Banana";
System.out.println(str1.compareTo(str2));

Returns:
# 0        → Strings are equal
# Negative → str1 comes before str2
# Positive → str1 comes after str2
----------------------------------------------------------------
10. compareToIgnoreCase()
----------------------------------------------------------------
# → Same as compareTo(), but ignores case differences.

Example:

String str1 = "Java";
String str2 = "java";
System.out.println(str1.compareToIgnoreCase(str2));

Output:
0
----------------------------------------------------------------
# 11. toLowerCase()  → Converts all characters of a String to lowercase.

----------------------------------------------------------------
# 12. toUpperCase() → Converts all characters of a String to uppercase.
----------------------------------------------------------------
13. trim() → Removes whitespace from the beginning and end of a String.
----------------------------------------------------------------
Example:
String str = "   Hello Java   ";
System.out.println(str.trim());

Output:
Hello Java
# → Does NOT remove spaces between words.
----------------------------------------------------------------
# 14. replace() → Replaces characters or sequences in a String.
----------------------------------------------------------------
Example:

String str = "Hello";
System.out.println(str.replace('l', 'x'));

Output:
Hexxo

Important:
# → String is immutable, so replace() returns a new String.
str = str.replace('l', 'x');
----------------------------------------------------------------
15. contains()
----------------------------------------------------------------
# → Checks whether a String contains a particular sequence.

Example:

String str = "Hello World";
System.out.println(str.contains("World"));

Output:
true
# → Returns true if present, otherwise false.
----------------------------------------------------------------
16. toCharArray()
----------------------------------------------------------------
# → Converts a String into a character array (char[]).

Example:

String str = "Java";
char[] arr = str.toCharArray();

Result:

J  a  v  a
# → Very useful in DSA for processing individual characters.
----------------------------------------------------------------
17. startsWith()
----------------------------------------------------------------
# → Checks whether a String starts with a particular sequence.

Example:

String str = "Hello World";
System.out.println(str.startsWith("Hello"));

Output:
true
----------------------------------------------------------------
18. endsWith()
----------------------------------------------------------------
# → Checks whether a String ends with a particular sequence.

Example:

String str = "Hello World";
System.out.println(str.endsWith("World"));

Output:
true
----------------------------------------------------------------
