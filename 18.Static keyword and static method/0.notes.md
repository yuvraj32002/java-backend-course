============================================================
                    STATIC KEYWORD IN JAVA
============================================================

1. WHAT IS STATIC?

• The `static` keyword is used to create members that belong
  to the CLASS rather than to individual OBJECTS.

• A static member is shared among all objects of the class.

Syntax:
    static dataType variableName;

Example:
    class Student {
        static String college = "ABC College";
    }
------------------------------------------------------------
2. WHY DO WE USE STATIC?
------------------------------------------------------------
• When a value or method is common to all objects, we can
  make it static.

Example:

    class Student {
        static String college = "ABC College";
        String name;
    }

Here:
#   college → Common for all students → static
#   name    → Different for each student → non-static
------------------------------------------------------------
3. STATIC VARIABLE
------------------------------------------------------------
# • A variable declared using the `static` keyword is called a STATIC VARIABLE.
# • It belongs to the class, not to individual objects.
• Only ONE copy of a static variable is created for the class.

Example:

    class Student {

        static String college = "ABC College";
        String name;

    }

    class Main {
        public static void main(String[] args) {

            Student s1 = new Student();
            Student s2 = new Student();

            s1.name = "Rahul";
            s2.name = "Aman";

            System.out.println(s1.name);
            System.out.println(s2.name);

            System.out.println(Student.college);
        }
    }

Output:

    Rahul
    Aman
    ABC College


# IMPORTANT: Student.college
# is preferred because `college` belongs to the class.
------------------------------------------------------------
4. STATIC VARIABLE vs INSTANCE VARIABLE
------------------------------------------------------------
STATIC VARIABLE:
• Belongs to the class
• One shared copy
• Can be accessed using class name
• Common among all objects

INSTANCE VARIABLE:
• Belongs to an object
• Separate copy for every object
• Accessed using object
• Can have different values for different objects

Example:

    class Student {

        static String college = "ABC College";  // static
        String name;                            // instance

    }
Memory concept:

    Student Class
        |
        └── college = "ABC College"
             ↑
             | shared
        ┌────┴────┐
        |         |
       s1        s2
        |         |
      name      name
     Rahul      Aman
------------------------------------------------------------
5. STATIC METHOD
------------------------------------------------------------
# • A method declared using `static` is called a STATIC METHOD.
• A static method belongs to the class.
• It can be called without creating an object.

Syntax:
#    static returnType methodName() {
        // code
    }
Example:
    class Calculator {

        static int add(int a, int b) {
            return a + b;
        }

    }

    class Main {

        public static void main(String[] args) {
            int result = Calculator.add(10, 20);
            System.out.println(result);
        }
    }
Output: 30

Here: Calculator.add(10, 20);...is used instead of:

    Calculator obj = new Calculator();
    obj.add(10, 20);
------------------------------------------------------------
6. IMPORTANT RULE OF STATIC METHOD
------------------------------------------------------------
# A static method can directly access:
    ✓ Static variables
    ✓ Static methods
# A static method cannot directly access:
#    ✗ Non-static / instance variables
#    ✗ Non-static / instance methods

Example:
    class Demo {
        int x = 10;
        static int y = 20;

        static void show() {
#            System.out.println(y);  // VALID
#            System.out.println(x);  // ERROR
        }
    }

# Why?
# Because `x` belongs to an OBJECT, while the static method belongs to the CLASS.
# The compiler does not know which object's `x` should be used.
------------------------------------------------------------
7. STATIC BLOCK
------------------------------------------------------------
# • A block declared using `static` is called a STATIC BLOCK.
# • It is executed when the class is loaded.
# Syntax:
#    static {
#        // code
#    }

Example:
    class Demo {
        static {
            System.out.println("Static block executed");
        }
        public static void main(String[] args) {
            System.out.println("Main method executed");
        }
    }

Output:

    Static block executed
    Main method executed

# IMPORTANT: Static block executes before the main() method.
------------------------------------------------------------
8. MULTIPLE STATIC BLOCKS
------------------------------------------------------------
# • A class can have multiple static blocks.
# • They execute in the order in which they are written.

Example:
    class Demo {
        static {
            System.out.println("Block 1");
        }
        static {
            System.out.println("Block 2");
        }
        public static void main(String[] args) {
            System.out.println("Main");
        }
    }
Output:
    Block 1
    Block 2
    Main
------------------------------------------------------------
9. STATIC CLASS
------------------------------------------------------------
# • In Java, a TOP-LEVEL CLASS cannot be static.
# • Only a NESTED CLASS can be declared static.

Example:
    class Outer {
        static class Inner {
            void show() {
                System.out.println("Hello");
            }
        }
    }
# A static nested class can be accessed without creating an object of the outer class.
Example:
#    Outer.Inner obj = new Outer.Inner();
#    obj.show();
------------------------------------------------------------
10. STATIC KEYWORD WITH main()
------------------------------------------------------------
# The main method is written as:  public static void main(String[] args)
Here:
#    public  → Accessible by JVM
#    static  → Can be called without creating an object
#    void    → Does not return a value
#    main    → Entry point of the program
#    String[] args → Command-line arguments

Why is main() static?

# Because the JVM needs to call the main() method without creating an object of the class.
------------------------------------------------------------
16. IMPORTANT POINTS
------------------------------------------------------------
1. `static` means the member belongs to the class.
2. Static members are shared among all objects.
3. Only one copy of a static variable exists per class (for a given class loader).
4. Static variables can be accessed using the class name.
5. Static methods can be called without creating an object.
6. Static methods can directly access static members.
# 7. Static methods cannot directly access instance members.
# 8. A static block executes when the class is initialized, before main() when main     triggers that class initialization.

# 9. A top-level class cannot be static.
# 10. A nested class can be static.

# 11. The `main()` method is static so that the JVM can invoke
    it without creating an object.
------------------------------------------------------------
17. EASY WAY TO REMEMBER
------------------------------------------------------------

STATIC
   ↓
BELONGS TO CLASS
   ↓
SHARED
   ↓
NO OBJECT REQUIRED


NON-STATIC
   ↓
BELONGS TO OBJECT
   ↓
INDIVIDUAL
   ↓
OBJECT REQUIRED
