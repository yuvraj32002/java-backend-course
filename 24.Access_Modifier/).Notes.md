# Access Modifiers in Java
## 1. What are Access Modifiers?
Access modifiers in Java are keywords used to **control the visibility and accessibility** of classes, methods, variables, constructors, and other members.
They help implement **encapsulation** by restricting access to certain parts of a program.
Java provides **4 access levels**:
1. `private`
2. `default` (package-private)
3. `protected`
4. `public`
---
# 2. Types of Access Modifiers
| Modifier       | Accessibility             |
|---             |---                        |
| `private`      | Same class only           |
| `default`      | Same package              |
| `protected`    | Same package + subclasses |
| `public`       | Everywhere                |
----------------------------------------------
# 3. Private Access Modifier
----------------------------------------------
The `private` modifier provides the **most restricted access**.
A `private` member can be accessed **only inside the class in which it is declared**.

## Syntax: private dataType variable;

Example

class Student {
    private String name;
    void setName(String name) {
        this.name = name;
    }
    void display() {
        System.out.println(name);
    }
}
Here, name is accessible inside the Student class. But it cannot be directly accessed outside the class:
class Main {
    public static void main(String[] args) {
        Student s = new Student();
        // s.name = "Yuvraj";   // ERROR
    }
}
# Why use private?
# private is commonly used for:

* Data hiding
* Encapsulation
* Protecting internal implementation
* Restricting direct modification of variables
----------------------------------------------
4. Default Access Modifier
----------------------------------------------
When no access modifier is specified, Java provides default access.
# Default access is also called: package-private
Example:

class Student {
    String name;   // default access
}
# The variable name can be accessed by classes belonging to the same package. It cannot be directly accessed by classes belonging to a different package.

# Important Point :- There is no default keyword used for normal default access.
# Eg: Correct  : String name;
#     Incorrect: default String name;
----------------------------------------------
5. Protected Access Modifier
----------------------------------------------
# The protected modifier provides access:
# 1. Within the same package
# 2. To subclasses, even if they are in a different package

# Syntax: protected dataType variable;

6. Protected with Inheritance
----------------------------------------------
# A subclass can access a protected member.

class Vehicle {
    protected int speed;
}
class Bike extends Vehicle {
    void showSpeed() {
        speed = 100;
        System.out.println(speed);
    }
}

Here, Bike inherits from Vehicle, so it can access the protected member speed.

7. Protected in Different Package
----------------------------------------------
# A protected member can also be accessed by a subclass located in another package.

Package 1

package vehicle;
public class Vehicle {
    protected int speed;
}

Package 2

package bike;
import vehicle.Vehicle;
public class Bike extends Vehicle {
    void showSpeed() {
        speed = 100;
        System.out.println(speed);
    }
}
This is allowed because Bike is a subclass of Vehicle.
⸻

# Important Rule: For protected:
# Same Package → Accessible
# Different Package + Subclass → Accessible
# Different Package + Non-Subclass → Not directly accessible
----------------------------------------------
8. Public Access Modifier
----------------------------------------------
The public modifier provides the widest accessibility.
# A public member can be accessed from anywhere, provided the class/member itself is accessible.
# Syntax: public dataType variable;
----------------------------------------------
9. Complete Access Modifier Table
----------------------------------------------
| Access Modifier | Same Class | Same Package | Different Package + Subclass | Different Package + Non-Subclass|
|-----------------|------------|--------------|-------------------------------|--------------------------------|
| `private`       | ✅         | ❌           | ❌                            | ❌                               |
| `default`       | ✅         | ✅           | ❌                            | ❌                               |
| `protected`     | ✅         | ✅           | ✅                            | ❌                               |
| `public`        | ✅         | ✅           | ✅                            | ✅                               |
----------------------------------------------
10. Access Level Hierarchy
----------------------------------------------
# From most restrictive → least restrictive: private < default < protected < public
----------------------------------------------
12. Real-World Usage
----------------------------------------------
# private Used for:

* Internal variables
* Sensitive data
* Data hiding
* Encapsulation
* Implementation details

# protected Generally useful when working with inheritance.

# public Used for functionality that should be exposed to other classes/packages.
----------------------------------------------
14. Access Modifiers for Top-Level Classes
----------------------------------------------
# For a top-level class, only these access levels are allowed:
# public
# default

A top-level class cannot be:

private class Student {
}

or:

protected class Student {
}

These are not allowed for top-level classes.

⸻

Public Top-Level Class

public class Student {
}

A public class can be accessed from other packages, subject to normal package/import rules.

⸻

Default Top-Level Class

class Student {
}

This class has package-private/default access.

It can be accessed only from the same package.

25. Interview Questions
----------------------------------------------
Q9. Can a top-level class be private?  Ans: No

Q10. Can a top-level class be protected? Ans: No

Q11. What is another name for default access? Ans: package-private
----------------------------------------------
26. Most Important Points for Exams
----------------------------------------------
1. Java has 4 access levels:
   private, default, protected, public
2. private:
   Same class only.
3. default:
   Same package only.
4. protected:
   Same package + subclasses.
5. public:
   Accessible everywhere.
6. No modifier = default/package-private.
7. private is the most restrictive.
8. public provides the widest access.
9. Top-level classes can be public or default.
10. Top-level classes cannot be private or protected.
