GITHUB SSH AUTHENTICATION — SHORT NOTES
=============================================

Purpose:
SSH authentication securely connects your computer with your GitHub account.


STEP 1: Generate SSH Key Pair
-----------------------------

ssh-keygen -o

Usually creates:

~/.ssh/
├── id_ed25519        → Private Key
└── id_ed25519.pub    → Public Key

Private key:
- Keep it on your computer.
- NEVER share it.

Public key:
- Add it to your GitHub account.


STEP 2: View Public Key
-----------------------

cat ~/.ssh/id_ed25519.pub

Copy the complete output.


STEP 3: Add Public Key to GitHub
--------------------------------

GitHub
→ Settings
→ SSH and GPG keys
→ New SSH key
→ Paste Public Key
→ Add SSH key


STEP 4: Test SSH Authentication
--------------------------------

ssh -T git@github.com

Successful authentication looks like:

Hi USERNAME! You've successfully authenticated,
but GitHub does not provide shell access.


IMPORTANT:
SSH authentication is normally a one-time setup
for a computer + GitHub account.

The same SSH key can be used for multiple repositories.


AUTHENTICATION ≠ REPOSITORY CONNECTION

Authentication:
"GitHub, this computer/user is authorized."

Repository connection:
"Connect this local repository to this GitHub repository."
