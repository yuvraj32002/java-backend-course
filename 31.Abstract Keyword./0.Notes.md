1. What is an Abstract Class?

An abstract class is a class declared using the abstract keyword.
It is used as a common base class for related classes and supports partial abstraction.

abstract class Shape {
    // members
}

# Important

* Cannot be instantiated directly.
* Can contain both abstract and concrete methods.
* Can contain constructors, variables, static methods and final methods.
* It is generally extended by a subclass.
# * A abstract may not contain the abstract method or may contain only normal methods.
* Normal class is known as concrete class, similarly normal method is known as concrete method.
════════════════════════════════════════════════════════════
2. Abstract Method :

An abstract method is declared without a body.
# The subclass must implement it unless the subclass is also abstract.

Abstract method
      ↓
No implementation in parent
      ↓
Child class provides implementation
════════════════════════════════════════════════════════════
3. Concrete Method

A concrete method is a normal method with a body.

void display() {
    System.out.println("Hello");
}
════════════════════════════════════════════════════════════
4. Basic Example

abstract class Shape {
    String color;
    Shape(String color) {
        this.color = color;
    }
    abstract double area();
    void getColor() {
        System.out.println("Color: " + color);
    }
}
class Circle extends Shape {
    int radius;
    Circle(String color, int radius) {
        super(color);
        this.radius = radius;
    }
    double area() {
        return 3.14 * radius * radius;
    }
}
class Main {
    public static void main(String[] args) {
        Shape s = new Circle("Red", 5);
        s.getColor();
        System.out.println(s.area());
    }
}

Output

Color: Red
78.5

Understand the flow

Shape
 ├── color
 ├── constructor
 ├── area()       → abstract
 └── getColor()   → concrete
        ↓
      Circle
        ↓
 implements area()

# Shape s = new Circle(...) is allowed because the reference is Shape but the actual object is Circle.

5. Abstract Class with Constructor

An abstract class can have a constructor. The constructor executes when a subclass object is created.

6. Important Properties

# ① Cannot be instantiated

abstract class A { }
A obj = new A();       // ERROR

But this is valid:

A obj = new B();

if B extends A.
────────────────────────────────────────────────────────────
# ② Can have NO abstract methods

abstract class A {
    void show() {
        System.out.println("Hello");
    }
}

A is still abstract even though it has no abstract method.
────────────────────────────────────────────────────────────
# ③ Can contain final methods

abstract class A {
    final void show() {
        System.out.println("Hello");
    }
}

A final method cannot be overridden by a subclass.
────────────────────────────────────────────────────────────
# ④ Can contain static methods

abstract class Helper {
    static void display() {
        System.out.println("Hello");
    }
}
Helper.display();

# No object is required because static methods belong to the class.
────────────────────────────────────────────────────────────
# ⑤ Can contain inner abstract classes

An inner class can also be declared abstract.

class Outer {
    abstract class Inner {
        abstract void show();
    }
}
────────────────────────────────────────────────────────────
7. Class Containing Abstract Method

# If a class contains at least one abstract method, the class itself must be abstract.

❌ Invalid:

class A {
    abstract void show();
}

✅ Valid:

abstract class A {
    abstract void show();
}
════════════════════════════════════════════════════════════
# 8. Subclass Can Also Be Abstract

# If a child class does not implement all inherited abstract methods, it must declared abstract.

abstract class A {
    abstract void m1();
    abstract void m2();
}
abstract class B extends A {
    void m1() {
        System.out.println("m1");
    }
    // m2() not implemented
}

B must be abstract because m2() is still unimplemented.

A further subclass can implement m2() and become concrete.

A
│
├── m1()
└── m2()
     ↓
B (abstract)
│
└── implements m1()
     ↓
C (concrete)
│
└── implements m2()

10. Abstract Class — Quick Rules

1. Declared using abstract keyword.
2. Cannot be instantiated directly.
3. Can have abstract methods.
4. Can have concrete methods.
5. Can have constructors.
6. Can have static and final methods.
7. Can have zero abstract methods.
8. A class containing an abstract method
   must be abstract.
9. A subclass that doesn't implement all
   abstract methods must also be abstract.
10. A concrete subclass can be instantiated.
════════════════════════════════════════════════════════════
11. Why Use Abstract Classes?

# Use an abstract class when multiple related classes share common properties/behavior but some behavior must be implemented differently.

Example:

             Shape
               │
       ┌───────┼────────┐
       ↓       ↓        ↓
    Circle  Rectangle  Triangle
       │       │        │
       └── different area() ──┘

The parent defines the common structure, while each child provides its own implementation.
