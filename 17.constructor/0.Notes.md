CONSTRUCTORS IN JAVA:-
-------------------------------------------------------------
1. What is a Constructor?
A constructor is a special member of a class that is automatically called when an object is created.

Main Purpose:-
# The main purpose of a constructor is to initialize the object.

2. Important Properties of Constructor
-------------------------------------------------------------
1. Constructor name must be the same as the class name.
2. Constructor does NOT have a return type. Not even void.
3. Constructor is called automatically when an object is created.
4. Constructor is mainly used to initialize object data.
5. Constructors can have parameters.
6. Constructors can be overloaded.
# 7. A constructor can have access modifiers such as ...public, protected, private, or default.
-------------------------------------------------------------
3. Constructor vs Method

Constructor                         Method
----------------------------------------------------------------
Used to initialize an object.       Used to perform an operation.
Must have same name as class.       Can have any valid name.
Has no return type.                 Has a return type or void.
Called automatically when           Usually called explicitly.
object is created.
# Cannot be inherited.                Methods can be inherited.

5. Default Constructor
-------------------------------------------------------------
A default constructor is a constructor with no parameters.
If you do not write any constructor in a class, Java automatically provides a default no-argument constructor.

Example

class Student {
    String name;
    int age;
}
class Main {
    public static void main(String[] args) {
        Student s = new Student();
        System.out.println(s.name);
        System.out.println(s.age);
    }
}

Output:

null
0

# The instance variables receive their default values.

String → null
int    → 0
boolean → false
double → 0.0

# Important Note: If you define any constructor yourself, Java does NOT automatically provide the default constructor.
-------------------------------------------------------------
6. Parameterized Constructor
-------------------------------------------------------------
A constructor that accepts one or more parameters is called a parameterized constructor.
It is used when we want to initialize an object with specific values.
-------------------------------------------------------------
7. Copy Constructor
-------------------------------------------------------------
A copy constructor creates a new object by copying the data of an existing object.
Java does NOT provide a built-in copy constructor like C++.

We create one ourselves.

Example

class Student {
    String name;
    int age;
    // Parameterized constructor
    Student(String name, int age) {
        this.name = name;
        this.age = age;
    }
    // Copy constructor
    Student(Student obj) {
        this.name = obj.name;
        this.age = obj.age;
    }
}

Creating objects:

Student s1 = new Student("Yuvraj", 20);
Student s2 = new Student(s1);

Here:

s1
 ├── name = Yuvraj
 └── age  = 20
       │
       │ copy
       ↓
s2
 ├── name = Yuvraj
 └── age  = 20

# Important: Student(Student obj)...is a constructor that takes an object of the same class as its parameter.
-------------------------------------------------------------
8. Private Constructor
-------------------------------------------------------------
# A constructor declared using the private access modifier is called a private constructor.

class Test {
    private Test() {
        System.out.println("Constructor called");
    }
}

# It cannot be accessed from outside the class.

Test obj = new Test();    // ❌ Error

Common Uses

# 1. Singleton Pattern → Restrict creation of objects.
# 2. Utility Classes → Prevent object creation when a class contains only static methods.
-------------------------------------------------------------
9. Constructor Overloading
-------------------------------------------------------------
When a class has multiple constructors with different parameter lists, it is called constructor overloading.
Example:-
class Student {
    Student() {
        System.out.println("No argument");
    }
    Student(String name) {
        System.out.println("Name: " + name);
    }
    Student(String name, int age) {
        System.out.println("Name: " + name);
        System.out.println("Age: " + age);
    }
}

Now we can create objects in different ways:

Student s1 = new Student();
Student s2 = new Student("Yuvraj");
Student s3 = new Student("Yuvraj", 20);

# Important Point: Constructor overloading is resolved at compile time.

new Student()
       ↓
No-argument constructor
new Student("Yuvraj")
       ↓
String constructor
new Student("Yuvraj", 20)
       ↓
String + int constructor

10. Constructor Chaining
⸻------------------------------------------------------
# Constructor chaining means calling one constructor from another constructor.
# It can be done using:
# this() → calls another constructor of the same class
# super() → calls constructor of the parent class

Example:

class Student {
    String name;
    int age;
    Student() {
        this("Unknown", 0);
    }
    Student(String name, int age) {
        this.name = name;
        this.age = age;
    }
}

Here:

Student()
   ↓
this("Unknown", 0)
   ↓
Student(String, int)

⸻

11. Constructor Initialization Flow

When we write:

Student s = new Student("Yuvraj", 20);

The basic flow is:

new
 ↓
Memory is allocated for object
 ↓
Constructor is called
 ↓
Object data is initialized
 ↓
Reference is assigned to s

13. Constructor — Key Points for Exams

✓ Constructor initializes an object.
✓ Constructor name must be the same as class name.
✓ Constructor has NO return type.
✓ Constructor cannot have a return type of void either.
✓ Constructor is automatically called when an object is created.
✓ Constructors can be parameterized.
✓ Constructors can be overloaded.
✓ If no constructor is written, Java provides a default
  no-argument constructor.
✓ If you write any constructor, Java does not provide the
  default constructor automatically.
✓ Java does not provide a built-in copy constructor like C++.
✓ A private constructor cannot be accessed from outside the class.
✓ Constructor overloading is resolved at compile time.

ONE-LINE DEFINITION

Constructor = A special member of a class that is automatically
called when an object is created and is mainly used to initialize it.
