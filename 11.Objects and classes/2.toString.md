        toString() & println() — NOTES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. WHAT IS toString()?
• toString() is a method defined in Java's Object class.
# • Every Java class ultimately inherits from Object.
# • Therefore, every object has a toString() method.
Example:
class Dog {
    ...
}
Dog → Object
     ↑
  inherits
  toString()

2. WHY DO WE OVERRIDE toString()?
# • The default Object.toString() does not provide useful information about the object's data.
Example:
System.out.println(tuffy);
Without overriding toString():
Dog@6d311334 // class_name_Hash_code //
# • We override toString() to define how our object should be represented as a String.
Example:
@Override
public String toString() {
    return "Name is: " + name;
}
# 3. HOW IS toString() CALLED IN OUR PROGRAM?
We write:
System.out.println(tuffy);// System.out.println(Object_name);
We DON'T explicitly write:
tuffy.toString();
But Java needs a String representation of the Dog object for printing.
Conceptually:
System.out.println(tuffy)
            ↓
      Dog object
            ↓
   Object → String representation
            ↓
      tuffy.toString()
            ↓
   Dog's overridden toString()
            ↓
      String returned
            ↓
         println()
            ↓
         Output

5. WHAT IF WE DON'T OVERRIDE toString()?
If Dog does not override toString():
System.out.println(tuffy);
Java uses the inherited method from Object:
Object.toString()
Output will look something like:
Dog@6d311334
The exact value after @ can vary.
6. PRIMITIVE vs OBJECT
Primitive data types:
int
double
float
char
boolean
long
short
byte
For example:
int age = 5;
System.out.println(age);
Here println() can directly use its overloaded method:
println(int)
# toString() is NOT called on the primitive.
7. OBJECT / REFERENCE TYPES
Examples:
Dog
Student
Car
ArrayList
Scanner
etc.
# When an object is passed to println() and the Object-based...printing path is used:
System.out.println(object);
Java obtains the object's String representation using:
object.toString()
If the class overrides toString(), the overridden version executes.
8. STRING IS ALSO AN OBJECT
String is a non-primitive/reference type.
Example:
String name = "Tuffy";
System.out.println(name);
# However, println() has a specific overload: println(String). So String can be printed directly through that overload.
9. IMPORTANT println() OVERLOADING
System.out.println() has different overloaded versions, such as:
println(int)
println(double)
println(char)
println(boolean)
println(String)
println(Object)
Therefore, Java selects the appropriate println() method
based on the type of value being passed.

• toString() → converts/represents an object as a String.
• toString() comes from Object class.
• Every class inherits it.
• We can override it.
• println() is overloaded.
• Primitive values use their specific println() overloads.
• Custom objects commonly use println(Object), which obtains
  their String representation via toString().
• Overriding toString() gives meaningful object output.
