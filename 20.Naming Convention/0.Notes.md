==================================================
             NAMING CONVENTIONS IN JAVA
==================================================
Naming Convention:
------------------
Naming conventions are standard rules used to name
classes, methods, variables, packages, and constants
in Java.
They make the code:
• Easy to read
• Easy to understand
• Consistent
• Easy to maintain

1. CLASS NAME
-------------
• Use PascalCase (UpperCamelCase).
• Each word starts with a capital letter.
• Should normally be a noun.

Example:
    Student
    StudentDetails
    BankAccount
    EmployeeRecord

❌ Bad:
    student
    studentdetails
    student_details

2. METHOD NAME
--------------
• Use camelCase.
• First word starts with lowercase.
• Every subsequent word starts with uppercase.
• Usually represents an action/behavior.

Example:
    calculateSalary()
    getStudentName()
    displayDetails()
    printResult()

❌ Bad:
    CalculateSalary()
    calculate_salary()
    displaydetails()

3. VARIABLE NAME
----------------
• Use camelCase.
• Start with a lowercase letter.
• Use meaningful names.
• Avoid unnecessary single-letter names.

Example:
    studentName
    totalMarks
    employeeSalary
    accountNumber

❌ Bad:
    StudentName
    total_marks
    x1   // if the meaning is unclear

4. CONSTANT NAME
----------------
• Use UPPERCASE.
• Separate multiple words using underscore (_).
• Constants are generally declared using 'static final'.

Example:
    MAX_VALUE
    MIN_VALUE
    PI
    MAX_STUDENTS
    DEFAULT_TIMEOUT

5. PACKAGE NAME
---------------
• Use lowercase letters.
• Multiple words are generally written together
  or separated using dots for different package levels.
• Usually starts with the reversed domain name.

Example:
    java.util
    java.lang
    com.company.project
    com.example.student

❌ Bad:
    Java.Util
    com.Company.Project

6. INTERFACE NAME
-----------------
• Use PascalCase.
• Usually represents a capability or behavior.

Example:
    Runnable
    Serializable
    Comparable
    Printable

Custom examples:
    Payment
    Printable
    Vehicle

7. ENUM NAME
------------
• Use PascalCase for the enum type.
• Enum constants use UPPERCASE.

Example:

    enum Direction {
        NORTH,
        SOUTH,
        EAST,
        WEST
    }

8. BOOLEAN VARIABLE / METHOD
----------------------------
Boolean names should clearly indicate a true/false
condition.

Common prefixes:
    is
    has
    can
    should

Examples:
    isActive
    isAvailable
    hasPermission
    canVote
    shouldUpdate()

11. RESERVED KEYWORDS
---------------------
Java keywords cannot be used as identifiers.
Examples of keywords:

    class
    int
    static
    public
    private
    void
    new
    return
    
❌ Invalid:

    int class = 10;

Because 'class' is a Java keyword.

12. IDENTIFIER RULES
--------------------
An identifier is the name given to a class, method,
variable, etc.

Rules:

• Can contain letters, digits, '_' and '$'.
• Cannot start with a digit.
• Cannot contain spaces.
• Cannot be a Java keyword.
• Java identifiers are case-sensitive.

Example:
    studentName       ✓
    student1          ✓
    _student          ✓
    $student          ✓

    1student          ✗
    student name      ✗
    class             ✗

QUICK REVISION
--------------

Class       → PascalCase
Method      → camelCase
Variable    → camelCase
Constant    → UPPER_CASE
Package     → lowercase
Enum        → PascalCase
Enum values → UPPER_CASE

IMPORTANT:
----------
Naming conventions are NOT compiler rules in most cases.
They are recommended coding standards used to make
Java programs readable, consistent, and maintainable.
